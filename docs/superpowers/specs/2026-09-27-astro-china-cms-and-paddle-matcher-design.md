# 众祺体育：Astro、大陆 CMS 与球拍匹配器设计

**日期：** 2026-09-27  
**状态：** 待用户审核  
**范围：** 将现有静态网站迁移为面向中国大陆访客与运营团队的可编辑网站，并新增球拍匹配体验。

## 目标

1. 保留现有网站的视觉语言、导航、GSAP 动效、知识文章和球拍商城体验。
2. 让非技术运营人员通过中文后台维护首页、赛事、文章、术语、球拍、价格、京东购买链接与 Club Edits。
3. 面向中国大陆提供稳定的公开访问和后台编辑体验。
4. 让用户可在 30–45 秒内获得 3 支球拍推荐，并可在结果后用低摩擦方式微调偏好。

## 已确认的决策

- 主要访客与日常编辑者均在中国大陆。
- 生产环境不使用 Vercel、Sanity 或 GitHub Pages；它们可作为开发预览工具，但不是生产依赖。
- 公开前台使用 Astro 静态生成。
- 内容后台使用 Strapi。
- 云端基础设施使用腾讯云中国大陆区域：云服务器运行 Strapi，COS 存储静态文件与媒体，EdgeOne 或 CDN 分发公开站点。
- 球拍匹配采用 4 题快速测验；雷达图只用于展示和反馈，不支持直接拖拽编辑。
- 推荐结果固定为 3 支球拍：最适合、更稳的选择、更进攻的选择。
- 结果页提供“再调一点”标签，例如“容错再高一点”“力量再强一点”，可即时重新排序并更新雷达图。

## 架构

```text
运营人员
  ↓ HTTPS
Strapi 管理后台（admin.<域名>）
  ↓ 发布事件
构建触发器
  ↓
Astro 静态构建
  ↓
腾讯云 COS（HTML / CSS / JS / 图片）
  ↓
腾讯云 EdgeOne 或 CDN
  ↓
中国大陆访客
```

### 内容发布

1. 运营人员在 Strapi 中保存草稿或发布内容。
2. 发布动作触发安全的构建 Webhook。
3. 构建任务读取已发布的 Strapi 内容，生成 Astro 静态站点。
4. 生成产物上传 COS，并按路径刷新 CDN 缓存。
5. 公开网站在数十秒到数分钟内更新。

构建失败时不覆盖上一版已发布站点；后台记录错误并通知管理员。前台在构建时仍继续服务上一版静态文件。

### 中国大陆适配

- 使用正式自有域名，不使用海外平台默认域名。
- 完成 ICP 备案后启用大陆 CDN 与正式域名。
- 站点字体、GSAP、图像和关键脚本均作为本地或 COS 资源，不依赖 Google Fonts、海外 CDN 或品牌海外图片链接。
- 图片统一由 Strapi 上传到 COS；保留图片 alt 文本与版权来源字段。

## 后台内容模型

| 类型 | 主要字段 | 使用位置 |
|---|---|---|
| 网站设置 | 俱乐部名称、Logo、首页标题、导语、购买入口、页脚 | 全站 |
| 赛事 | 名称、类型、简介、状态、链接、排序、是否显示 | 赛事区 |
| 知识文章 | 标题、Slug、摘要、正文、封面、原始链接、发布日期、状态 | 知识页与文章页 |
| 术语 | 术语、中文解释、示例、分类、排序 | 术语页 |
| 球拍 | 名称、系列、Slug、图片、人民币售价、厚度、形状、握柄长度、参数、中文介绍、京东购买链接、上架状态、排序 | 商城、详情、匹配器 |
| Club Edits | 标题、文案、图片、链接、排序、状态 | Club Edits 区 |

### 球拍性能字段

每支球拍额外维护 1–10 的内部评分和结构标签：

- 控制、力量、容错、速度、旋转；
- 适合水平（入门、进阶、竞赛）；
- 打法（控制、全场、力量）；
- 常用区域（网前、中场、底线、全场）；
- 形状（宽体、混合、加长）；
- 握柄长度与双手反拍适配度；
- 手感（柔和、平衡、直接）；
- 预算档位与上架状态。

这些评分是运营后台字段，不对访客显示为“实验室测试结果”。页面对用户展示的是经编辑审核的球拍特点与雷达图。

## 后台权限

| 角色 | 可做的事 |
|---|---|
| 管理员 | 配置栏目、管理用户、编辑所有内容、发布与查看构建状态 |
| 内容编辑 | 编辑赛事、知识文章、术语与 Club Edits；不能管理用户或系统配置 |
| 商品运营 | 编辑球拍价格、图片、库存／上架状态、京东链接、排序与性能标签 |
| 访客 | 仅阅读公开网站 |

后台使用独立子域名 `admin.<域名>`，仅允许受邀账号登录。生产密钥只保存在腾讯云环境变量中，不进入 Git 仓库。

## 球拍匹配器

### 入口与定位

在首页装备区和商城页设置“还不确定该选哪支？开始匹配”入口。匹配器不要求登录、不收集个人身份信息，也不作医疗或竞技能力承诺。

### 4 题快速测验

1. **当前阶段：** 刚开始／能稳定对打／正在进阶／常参加比赛。
2. **下一阶段目标：** 更稳定控球／更有进攻力量／更快的网前反应／更全面均衡。
3. **常用区域：** 网前／中场衔接／底线／都差不多。
4. **偏好手感：** 柔和、容错高／直接、有弹性／两者平衡；并提供可跳过的“双手反拍”选项。

每题使用大按钮、简短解释和可返回上一步的导航；不在测验阶段要求用户理解厚度、挥重或雷达图。

### 推荐计算

测验回答转化为目标向量（控制、力量、容错、速度、旋转）以及硬条件（水平、场区、手感、双反）。

1. 先排除未上架和不符合硬条件的球拍。
2. 按目标向量与球拍性能字段的加权距离计算匹配分。
3. 返回三种有意义的候选：综合最高分、容错／控制偏高、力量／速度偏高。
4. 每张结果卡生成清晰理由，列出用户选择与球拍字段之间的对应关系。

匹配分用于排序，不以百分比或“科学精准”语言对外宣称。若没有球拍能同时满足高力量和高容错，页面明确说明当前产品中的最佳折衷及其代价。

### 结果后微调：再调一点

结果页展示“你的当前需求”雷达图与三张候选球拍雷达图。用户不能拖动雷达图，而是可点选以下标签：

- 容错再高一点；
- 力量再强一点；
- 网前再快一点；
- 控制再稳一点。

用户可以选择一个或两个标签。每次点击：

1. 仅提高相应目标维度的权重；
2. 用短动画更新需求雷达图；
3. 即时重新排序三张推荐卡；
4. 更新推荐理由和取舍提示；
5. 提供“重新回答”以重置整个测试。

这避免移动端五轴拖拽的精度和理解负担，同时保留用户在看到结果后的掌控感。

### 购买转化

每张结果卡可查看站内详情，或通过后台设置的京东链接前往购买。页面显示后台维护的人民币售价，不显示“参考价”或海外美元价格。商品价格、库存和链接由商品运营人员负责更新。

## 前端迁移范围

- 将 `index.html`、`shop.html`、`product.html`、文章页和现有 CSS／JS 转为 Astro 页面、布局与组件。
- 抽出 Header、Footer、赛事列表、知识卡片、球拍网格、球拍详情、雷达图、测验步骤和结果卡等组件。
- 继续使用 GSAP，但仅用于既有页面动效与可访问的界面反馈；为减少动态效果用户提供无动画版本。
- 采用响应式布局、键盘导航、可见焦点与减少动态效果偏好。
- 建立原地址重定向，维持现有知识文章和商城链接的可访问性。

## 上线前依赖与责任

用户需准备或授权：

1. 腾讯云账号、实名认证与付费方式；
2. 正式域名及 DNS 控制权；
3. ICP 备案所需主体材料；
4. 后台管理员邮箱和运营人员列表；
5. 17 款球拍的人民币实际售价、对应京东购买链接和商品可售状态；
6. 必要时的商品图片使用授权或可上传的原图。

实施方负责：代码迁移、Strapi 内容类型、内容导入脚本、构建／发布流程、权限初始配置、测试和上线文档。ICP备案审批、云服务订购、域名所有权验证和商品商业信息准确性由用户方完成。

## 验收标准

- 运营人员无需 Git 或代码编辑即可修改所有定义的内容类型。
- 一次正常发布可使公开站在可预期时间内更新，失败不影响上一版生产站。
- 中国大陆桌面与移动网络下可加载本地化的核心资源，不依赖海外关键资源。
- 用户可在 4 题以内获取 3 支推荐，并通过最多两个“再调一点”标签更新结果。
- 推荐结果显示原因、取舍和京东购买入口；价格只显示人民币后台售价。
- 现有首页、赛事、知识、装备、Club Edits 与文章链接都能迁移且不丢失。
