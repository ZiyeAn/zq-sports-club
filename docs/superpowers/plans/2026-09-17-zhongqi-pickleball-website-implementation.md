# 众祺匹克球俱乐部网站 · 实施计划

日期：2026-09-17  
依据：[设计规格](../specs/2026-09-17-zhongqi-pickleball-website-design.md)  
状态：待实施确认

## 实施范围

创建一个不依赖构建工具的单页展示网站，使用现有 Logo v2 与可替换内容数据。不会删除或覆盖现有素材；不会建立后台、抓取服务、账户、报名、支付或商城。

## 计划文件

| 文件 | 责任 |
| --- | --- |
| `index.html` | 语义化页面骨架：导航、首屏、赛事、知识、Warping Point、Club Edits、关于与页脚。 |
| `tokens.css` | 颜色、字体、间距、字号、缓动、时长和边界的统一令牌。 |
| `styles.css` | 网格编排、响应式布局、卡片、焦点状态、图片占位和减少动态效果样式。 |
| `script.js` | 内容卡片数据渲染、移动导航、锚点跳转、渐进显示与“即将开放”交互。 |
| `.hallmark/log.json` | 记录本次设计的结构、主题和视觉选择，便于后续迭代保持差异化。 |

## 步骤

1. 建立设计令牌与页面基础。
   - 在 `tokens.css` 定义暖白、近黑、运动绿的命名令牌，以及中文显示字体、正文、间距与动效令牌。
   - 在 `index.html` 引用 Logo v2、样式和脚本；建立清晰的页面地标与跳过导航链接。
   - 在 `styles.css` 添加页面级 `overflow-x: clip`、可见焦点环与最小化动效基础规则。

2. 组装首页的俱乐部叙事。
   - 用不对称细网格建立首屏：俱乐部名称、中文主张、赛事／知识／装备导航和“即将开放”入口。
   - 使用现有 Logo v2；不重绘 Logo，不伪造球员照片。
   - 首屏行动入口仅展示“即将开放”，不会提交任何数据。

3. 实现赛事与知识内容层。
   - 在 `script.js` 用本地可编辑的对象数组驱动赛事、知识与技巧卡。
   - 每张赛事卡具有英文官方赛事名、中文说明、地区／日期／来源字段；未确认内容显示“信息待确认”。
   - 每张知识卡提供分类、标题、摘要和阅读状态，不宣称实时更新。

4. 实现装备与未来商业入口。
   - 建立 Warping Point Pickleball Paddle 品牌展示与球拍选择建议区。
   - 不呈现价格、库存、评价、销量或未获确认的型号信息。
   - 建立 Club Edits 周边预告，状态明确为“即将开放”。

5. 完成微交互与无障碍体验。
   - 为卡片、导航和按钮提供默认、悬停、键盘焦点、按下与不可用状态。
   - 仅使用透明度与变换的短时过渡；添加一个低调的运动绿浏览提示。
   - `prefers-reduced-motion` 下关闭空间移动，保留短淡入或静态状态。

6. 验证与修整。
   - 用本地预览检查 320、375、414、768 与桌面宽度。
   - 验证没有横向滚动、可点击文字不换成两行、图片网格可收缩、中文标题不会溢出。
   - 逐项检查键盘导航、焦点可见性、链接语义、图像替代文本和“即将开放”状态。
   - 进行 Hallmark 视觉自检：无虚构指标、无模板化 Chrome、色彩和字体均从令牌引用、页面不复制参考图像素。

## 验收结果

完成后应交付一个可直接在浏览器打开的响应式网站。它能清晰传递“众祺匹克球俱乐部”的高级社群形象，以全球赛事和匹克球知识为重点，展示 Warping Point，并为 Club Edits 与后续运营能力预留结构化入口。
